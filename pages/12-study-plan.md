# 12. 학습 전략과 8주 플랜

## 가중치대로 공부하라

시험은 도메인별 가중치가 공개되어 있습니다. 공부 시간도 그 비율을 따라가는 것이 합리적입니다. 주당 10시간을 공부한다면 대략 이렇게 배분합니다.

| 도메인 | 비중 | 주당 시간 (10시간 기준) |
|---|---|---|
| D1 에이전트 아키텍처 | 27% | 2시간 40분 |
| D3 Claude Code | 20% | 2시간 |
| D4 프롬프트 엔지니어링 | 20% | 2시간 |
| D2 도구 설계와 MCP | 18% | 1시간 50분 |
| D5 컨텍스트와 신뢰성 | 15% | 1시간 30분 |

이 책의 Part 구성도 이 원칙을 따릅니다. 분량이 많은 Part일수록 시험 비중이 큽니다.

## 8주 플랜

| 주차 | 학습 내용 | 산출물 |
|---|---|---|
| 1주차 | Part 1 정독, Claude 계정과 API 키 준비, 개발 환경 세팅 | 학습 노트, 환경 구축 완료 |
| 2주차 | Part 2 (20장): 에이전트와 워크플로우 기초 | 5개 패턴 정리 노트 |
| 3주차 | Part 2 (21~22장): 오케스트레이션과 평가 | 간단한 에이전트 루프 코드 |
| 4주차 | Part 3 (30~31장): 도구 설계와 MCP 이론 | 도구 설계안 3종 작성 |
| 5주차 | Part 3 (32장) + Part 7: MCP 서버 실습과 프로젝트 | 동작하는 MCP 서버 1개 |
| 6주차 | Part 4 (40~42장): Claude Code | CLAUDE.md와 커스텀 커맨드 1개 |
| 7주차 | Part 5~6: 프롬프트와 컨텍스트 | 구조화 출력 실습 코드 |
| 8주차 | Part 8 모의고사 2회 + Part 9 정리, 오답 복습 | 모의고사 80% 이상 정답률 |

초급자라면 1~2주를 더해 10주 플랜으로 늘리는 것을 권장합니다. 특히 5주차의 MCP 실습은 처음 해보는 사람에게 시간이 걸립니다. 무리하게 진도를 빼기보다, 손으로 직접 해보는 분량을 지키는 쪽이 합격에 가깝습니다.

## 일일 루틴 예시 (평일 1시간 30분)

- 30분: 해당 장 읽기
- 40분: 예제 코드 실행과 변형 실습
- 20분: 장 끝 확인 문제를 노트에 정리

주말에는 3시간 블록을 잡아 프로젝트나 모의고사에 씁니다. 매일 조금씩보다, 주말에 몰아서 하는 방식은 에이전트 같은 큰 주제에서 흐름이 끊깁니다.

## 준비물

- 컴퓨터: Python 3.10 이상이 설치된 환경
- Claude 계정: API 실습용. 무료 티어로 시작해도 되지만, 토큰 사용량이 늘면 유료 플랜을 고려하세요
- 에디터: VS Code 권장
- Node.js: MCP 실습에서 TypeScript SDK를 쓴다면 필요 (이 책은 Python SDK 기준)
- Claude Code: Part 4에서 설치 안내

## 공식 학습 자료

- Anthropic Academy의 공개 과정: API, Claude Code, MCP 입문 과정이 무료로 제공됩니다
- Anthropic 공식 문서(docs): 프롬프트 엔지니어링 가이드와 API 레퍼런스
- Building Effective Agents: Anthropic 엔지니어링 블로그의 에이전트 설계 글. D1의 사실상 교과서입니다
- MCP 공식 문서: 아키텍처와 스펙

공식 과정과 이 책을 병행하면 이해가 빠릅니다. 공식 과정이 "무엇"을 알려준다면, 이 책은 "시험에서 어떻게 물어보는지"와 "손으로 어떻게 만드는지"에 초점을 맞춥니다.

## 흔한 실패 패턴

첫째, 프롬프트 엔지니어링만 파고드는 것입니다. D4는 20%로 중요하지만, D1(27%)과 D3(20%)를 놓치면 합격이 어렵습니다.

둘째, 코드 없이 이론만 읽는 것입니다. 시나리오형 문항은 "이런 상황에서 무엇을 선택하겠는가"를 묻습니다. 직접 만들어본 사람과 읽어본 사람의 답은 다릅니다.

셋째, 최신 정보를 확인하지 않는 것입니다. 응시료, 시험 정책, MCP 스펙은 바뀝니다. 시험 2주 전에는 공식 시험 가이드를 다시 읽으세요.
