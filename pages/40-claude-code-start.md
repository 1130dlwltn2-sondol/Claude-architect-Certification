# 40. Claude Code 시작하기

Part 4에서는 시험 비중 20%의 Domain 3을 다룹니다. Claude Code는 터미널에서 동작하는 Anthropic의 공식 코딩 에이전트입니다. 시험에서는 설치부터 설정, 워크플로우 자동화까지의 실사용 능력을 묻습니다.

## Claude Code란

Claude Code는 명령줄에서 실행되는 에이전트형 코딩 도구입니다. 자연어로 지시하면 코드를 읽고, 파일을 고치고, 테스트를 돌리고, 커밋까지 합니다. 20장에서 배운 에이전트 루프가 실제로 구현된 모습을 여기서 볼 수 있습니다.

다른 코딩 도구와의 차이는 에이전트로서의 자율성입니다. 단순히 코드를 완성해주는 수준이 아니라, 프로젝트 전체를 탐색하고 계획을 세운 뒤 여러 파일에 걸친 작업을 수행합니다. 이 과정에서 21장의 오케스트레이션 패턴(서브에이전트 활용)이 내부적으로 동작합니다.

## 설치

Node.js 18 이상이 필요합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

설치 후 첫 실행:

```bash
cd 내프로젝트
claude
```

처음 실행하면 로그인 과정을 거칩니다. Anthropic 계정으로 인증하면 됩니다.

버전 확인과 업데이트:

```bash
claude --version
npm update -g @anthropic-ai/claude-code
```

시험에서는 "최신 버전 유지" 같은 운영 관점도 물어볼 수 있습니다. 팀 단위로 버전을 맞추는 것이 재현성에 중요합니다.

## 첫 세션

프로젝트 디렉토리에서 claude를 실행하면 대화형 세션이 시작됩니다. 해볼 것들:

- "이 프로젝트의 구조를 설명해줘" : 코드베이스 탐색
- "로그인 함수에 대한 테스트를 만들어줘" : 테스트 생성
- "이 파일의 버그를 찾아줘" : 코드 리뷰

Claude Code는 현재 디렉토리를 작업 공간으로 삼습니다. 프로젝트 루트에서 실행하는 것이 기본입니다.

## 권한 모드

Claude Code는 파일 수정이나 명령어 실행 같은 동작을 할 때 권한을 묻습니다. 모드를 이해하는 것이 중요합니다.

- 일반 모드: 동작마다 승인 여부를 묻습니다
- 자동 승인 모드: 미리 정한 범위의 동작은 묻지 않고 실행합니다
- 읽기 전용 모드: 파일을 읽기만 하고 수정하지 않습니다

시험 포인트: 위험한 동작(삭제, 외부 전송, 결제 등)은 자동 승인을 주지 않는 것이 원칙입니다. 22장의 가드레일 개념과 연결됩니다.

## 기본 명령어

| 명령어 | 동작 |
|---|---|
| /help | 도움말 |
| /clear | 대화 기록 초기화 |
| /mcp | MCP 서버 상태 확인 |
| /agents | 서브에이전트 관리 |
| /config | 설정 변경 |

/clear는 컨텍스트 관리와 직결됩니다. 대화가 길어져 컨텍스트가 찼을 때, 새 작업을 시작하며 초기화하는 것이 기본기입니다. Part 6에서 자세히 다룹니다.

## 예제: 버그 수정 세션

"주문 금액이 10만 원을 넘으면 할인율이 적용되지 않는 버그가 있어. 원인을 찾아서 고쳐줘."

Claude Code의 내부 동작:

1. 코드베이스에서 주문, 할인 관련 파일을 탐색 (서브에이전트 활용 가능)
2. 할인 계산 로직을 읽고 조건식을 확인
3. 문제를 특정하고 수정안 제시 또는 직접 수정
4. 관련 테스트를 실행해 검증

사용자가 보는 것은 한 줄의 지시지만, 뒤에서는 탐색-계획-실행-검증의 루프가 돕니다.

## 실습: 첫 세션 기록하기

연습용 작은 프로젝트(또는 이 책의 예제 코드 폴더)에서 다음을 해보고 과정을 기록합니다.

1. 프로젝트 구조 설명 요청 후, 설명이 정확한지 직접 확인
2. 간단한 함수 하나를 만들어달라고 요청
3. 만든 코드에 대한 테스트 생성 요청
4. 각 단계에서 Claude Code가 어떤 파일을 읽었는지 관찰

4번이 중요합니다. 에이전트가 무엇을 근거로 판단하는지 보는 습관이, 나중에 직접 에이전트를 설계할 때 도움이 됩니다.

확인 문제

1. Claude Code의 작업 공간은 어떻게 정해지나요?
2. 권한 모드 3가지를 설명하고, 각각 언제 쓰는지 말해 보세요.
3. /clear를 쓰는 이유를 컨텍스트 관점에서 설명해 보세요.
4. Claude Code의 내부 동작을 20장의 패턴으로 설명해 보세요.
