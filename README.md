# Claude Certified Architect 자격증 준비

초급자부터 시작하는 Claude 인증 아키텍트(CCA-F) 실전 대비서입니다.

Anthropic이 2026년 3월에 출시한 Claude Certified Architect – Foundations 시험의 5개 평가 도메인을 처음부터 끝까지 다룹니다. 에이전트 아키텍처, MCP와 도구 설계, Claude Code, 프롬프트 엔지니어링, 컨텍스트 관리까지, 시험에 필요한 개념을 쉬운 설명과 실제 사례, 직접 해보는 실습으로 익힙니다.

책의 마지막에는 MCP 서버를 직접 만들고 Claude Code와 연동하는 실전 프로젝트, 도메인 가중치를 반영한 모의고사 40문항과 상세 해설, 시험 당일 전략을 수록했습니다.

- 대상 독자: Claude로 무언가를 만들어 본 적 없는 초급자부터, 실무에 AI를 도입하려는 개발자와 솔루션 아키텍트까지
- 기준일: 2026-04-05 (시험 제도 변경 사항은 공식 시험 가이드를 함께 확인하세요)
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~9 본문 24개 장, 실전 프로젝트, 모의고사, 마무리
- 저장소: https://github.com/lsszz2100/Claude-architect-Certification
