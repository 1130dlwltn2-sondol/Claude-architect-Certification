# Claude Certified Architect 자격증 준비

Claude 인증 아키텍트(CCA-F)를 준비하며, 시험 개념을 실제 AI 시스템 설계와 연결하고 싶은 독자를 위한 입문부터 실전까지의 학습서입니다. 에이전트 아키텍처, 도구 설계와 MCP, Claude Code, 프롬프트 엔지니어링, 컨텍스트 관리와 신뢰성을 설명과 실습으로 익힙니다.

## 대상 독자와 학습 수준
- Claude와 AI 개발을 처음 배우는 입문자, 실무에 AI를 도입하려는 개발자와 솔루션 아키텍트, CCA-F 응시를 준비하는 독자를 대상으로 합니다.
- 기초 개념과 8주 학습 플랜에서 시작해 도구 구현, 시스템 운영, 실전 프로젝트와 모의고사로 이어집니다.
- Python 코드와 터미널 명령을 따라 해 보는 실습이 포함되어 있습니다.

## 이 책으로 만드는 결과물
- 문서 검색 도구와 문서 읽기 기능을 제공하는 Python MCP 서버
- MCP 서버를 Claude Code에 연결한 사내 지식 어시스턴트
- 에이전트 평가와 운영을 점검하는 학습 노트, 모의고사로 확인한 복습 목록

## 실전 프로젝트와 구성
실전 프로젝트에서는 사내 기술 문서를 검색하는 MCP 서버를 구현하고, MCP Inspector로 테스트한 뒤 Claude Code와 연결합니다. 문서 근거가 답변에 반영되는지 확인하고 검색 개선, 권한과 신뢰성까지 살펴봅니다. 모의고사 40문항과 정답·해설로 학습 내용을 점검합니다.

- 학습 챕터 **22개**: Part 1~9의 본문, 실전 프로젝트, 모의고사·해설, 마무리를 포함합니다.
- 전체 목차 **25개 페이지**: 위 학습 챕터와 첫 페이지·책 소개·전체 목차 3개를 합한 수입니다.
- 읽는 순서: 자격증 개요와 학습 전략 → 5개 평가 도메인 관련 개념·실습 → MCP 지식 어시스턴트 프로젝트 → 모의고사와 해설 → 다음 학습 단계
