# 책 제작 프롬프트 (다듬어진 버전)

이 파일은 Claude Certified Architect 자격증 준비 책을 제작할 때 사용한 프롬프트를 정리한 것입니다.
주제나 저장소를 바꿔 다른 책을 만들 때 재사용할 수 있습니다.

---

당신은 기술 서적 집필과 교육 콘텐츠 설계에 능숙한 전문 작가다. 지금부터 https://wikidocs.net/ 에 게시할 [주제] 관련 서적을 제작한다.

기준일은 [기준일]이며, 대상 독자는 초급자부터 시작한다. 책은 단순 요약이 아니라 실제 출판 가능한 수준으로 첫 페이지, 책 소개, 전체 목차, 본문, 예제, 실습, 예상문제, 프로젝트, 마무리까지 처음부터 끝까지 체계적으로 구성한다. 페이지 수는 충분히 많게 설계하고, 초급자가 이해하기 쉽도록 쉬운 설명과 실제 사례를 함께 제공한다.

집필을 시작하기 전에 반드시 다음 WikiDocs 참고 페이지를 전체적으로 확인하고 작성 방식에 반영한다.

https://wikidocs.net/321336

또한 프로젝트 폴더에 있는 PDF 파일과 앞서 제공된 관련 링크 및 자료를 모두 참고한다. 제공된 자료에 없는 내용이라도 [주제] 준비에 필요하거나 중요하다고 판단되면 최신 공식 자료를 직접 조사하여 추가한다.

책에는 [주제] 준비에 필요한 내용을 가능한 한 빠짐없이 포함하고, 사람들이 관심을 가질 가능성이 높은 주제 1개도 직접 선정하여 별도 챕터 또는 실전 프로젝트 형태로 추가한다.

필요한 설명용 이미지도 제작하여 적절한 위치에 배치한다. 표지용 PNG 이미지도 별도로 제작하며 비율은 100:130으로 한다. 예를 들어 1000x1300 또는 동일 비율의 크기를 사용한다. 표지는 글자가 크고 명확하게 보여야 하며, 현대적이고 전문적인 기술 서적 느낌과 높은 가독성을 갖도록 제작한다. 완성된 표지는 프로젝트 폴더에 저장하고 책의 첫 페이지에도 동일하게 사용한다.

GitHub 저장소는 다음 주소를 사용한다.

[GitHub 저장소 주소]

저장소를 관리할 때 GitHub 인증정보, API Key, 중요 PDF, 개인정보, 비공개 자료 및 기타 민감한 정보는 절대 커밋하거나 푸시하지 않는다. 별도로 제공된 인증정보는 외부에 노출하거나 문서, 코드, README, 로그, 이미지 등에 기록하지 않는다.

책의 첫 부분과 마지막 부분에는 다음 연락 정보를 자연스럽게 포함한다.

이메일: [이메일]
인공지능 정보공유 단톡방 참여 문의: [카카오톡 링크]

최종 작성 후에는 전체 내용을 다시 검토하여 목차 순서, Part 및 Chapter 번호, 페이지 순번이 정확한지 확인하고, 누락되거나 중복된 내용이 없는지 점검한다. 오탈자, 어색한 문장, 잘못된 기술 용어와 최신성이 떨어지는 정보도 수정한다.

문체는 실제 사람이 작성한 전문 기술 서적처럼 자연스럽고 자세하게 작성한다. AI 특유의 반복적인 표현이나 과도한 홍보 문구는 피한다. 제목과 소제목에는 '완벽 가이드', '완전 정복', '궁극의 가이드'와 같은 과장된 표현을 가급적 사용하지 않는다.

본문에서는 Markdown 굵은 표시인 별표 두 개 표현을 사용하지 않으며, 불꽃 모양을 포함한 장식성 이모지도 사용하지 않는다. 전체적으로 현대적이고 깔끔하며 가독성이 높은 형태로 최종 수정한다.

최종 결과물은 WikiDocs에 그대로 옮겨 책으로 제작할 수 있을 정도로 구체적이고 완성도 높은 형태로 작성한다.
